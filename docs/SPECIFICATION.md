# Bijoy-Compatible Unicode Keyboard Specification

## Goal

Create an open-source Android keyboard that supports:

- Unicode Bangla
- Physical USB keyboard (OTG)
- Bluetooth keyboard
- Desktop-style typing experience

## Engine

Input:
Physical key

Output:
Unicode Bangla text

## Supported

- Letters
- Vowel signs
- Numbers
- Symbols
- Juktakkhor
- Reph
- Ref
- Hasanta

Status:
Draft
